# 观战指南：看 AI 打 AI

本项目的观战方案不依赖联机 observer：**地图触发器**负责揭图、保护玩家、
定期把 AI 囤在家里的部队赶出去。单人遭遇战即可全速运行。

## 1. 一次性设置

| 位置 | 设置 | 作用 |
| --- | --- | --- |
| 选项 → 操作 | 勾 **鼠标滚轮缩放** | 滚轮缩放，按一下滚轮复位 |
| 选项 → 显示 | 缩放 **自动** 或 **100%** | 视野大，适合看全局 |
| 选项 → 界面选项 | 生命条 **所有单位** | 一眼看出谁快死了 |
| 选项 → 游戏 | 关闭 **窗口失焦暂停**（可选） | 切出去查资料时对局不停 |

## 2. 开一局

1. **单人游戏 → 遭遇战**
2. 地图选 **Super AI Ice Lake 1v7 No Ore**（推荐）或任意 Flat 图
3. 自己坐 **Start 1**（Flat 30/120 的位置在可玩区内，进图按 `D` 就地展开）
4. 加 7 个电脑（30/120 图按槽位加满），难度 **冷酷 / 困难**
5. 队伍 **关闭（FFA）**，否则 AI 会结盟、不互打
6. 游戏选项：基地 **开**、快速游戏 **关**、战争迷雾 **关**、资金 10000–100000
7. 开始游戏，**不需要输入任何指令**

进图 1 秒后全图自动点亮；0 号位在第 1 秒先吃一次铁幕，之后每 10 秒补一次
（每次 50 秒），所以只要基地车不挪窝就一直是无敌状态；每 20 秒还会清一次 AI 家里的积压部队。

> **必须坐 Start 1。** All to Hunt 的动作目标是 1 号位之后的 AI 槽位
> （Ares `Player @ X` 选择器 `0x117B + slot`）。坐别的位会漏掉一家 AI，
> 甚至把你自己当成目标。

## 3. 镜头操作

| 操作 | 效果 |
| --- | --- |
| 滚轮 | 缩放（需在选项中开启） |
| 按住滚轮 / 中键 | 复位缩放 |
| 方向键 / 鼠标推到屏幕边缘 | 平移 |
| 点击小地图 | 跳转 |
| `Tab`（LAN 观战） | 切换跟随对象 |

本地遭遇战没有 observer 侧边栏，你是「站在地图外的玩家」：
镜头可以随便移，但没有击杀统计面板。

## 4. 各张地图怎么选

| 地图 | 适合 | 说明 |
| --- | --- | --- |
| **Ice Lake 1v7 No Ore** | 默认观战 | 8 人、地形有冰湖，视觉最好；玩家在可玩区外 |
| **Ice Lake 1v7** | 想看采矿 | 保留矿石，AI 会派矿车；建造速度会比无矿版慢 |
| **Flat 200** | 8 人纯平舞台 | 200×200，玩家 0 号位同样吃开局铁幕 + 全图揭示 |
| **Flat 30** | 30 家混战 | 250×250，玩家在可玩区左下角 (19,256)，基地车进图按 `D` 就地展开 |
| **Flat 120** | 极限大场面 | 500×500，120 家；玩家在可玩区左下角 (19,506)，同样可就地展开 |
| **Flat Snow 120 Center** | **站在战场正中看 119 家围过来** | 纯平雪地、无任何物件；玩家在地形正中 (150,150)，开局即被铁幕罩住、之后每 10 秒刷新一次；119 家均匀铺满全图（最近邻 22–30 格） |

Flat 地图全部是同一块平地、同一高度，建筑可以任意摆放，不会被地形或矿挡住。

## 5. 推荐参数

| 想看什么 | 设置 |
| --- | --- |
| 快节奏混战 | 7 AI，FFA，资金 10000，快速游戏开 |
| 大场面铺基地 | 7 AI，FFA，资金 100000，快速游戏关 |
| 看单家运营 | 2–3 个 AI，FFA，资金 10000 |
| 看超级武器 | 超级武器开；AI 的铁幕/超时空触发器权重 5000 |
| 30/120 家 | 按地图槽位加满 AI；资金 10000 起步，避免开局卡顿 |

- **战争迷雾关**：观战更清楚。
- **快速游戏关**：不会因为一家被拆光就立刻结束。
- 资金 100000 时电脑开局约 1 亿，铺得更疯。

## 6. 联机真观战（备选）

需要真正的 observer 视角（Tab 跟随、观战者侧边栏、自动全图）时：

1. **网络 (LAN) → 新游戏**，建房时勾 **允许观战**
2. 加 3–4 个 AI，难度冷酷
3. 把自己拖到 **观战者** 组，或点观战者标题的 **观战**
4. 开始游戏；`Tab` 切换跟随 AI，最后一位是上帝视角

限制：联机有网络时钟，**6 档 = 90 帧/秒是上限**，7 档「无限制」在网络里只有 60；
时钟还会按 CPU 处理时间自适应下调。单机遭遇战没有这个限制。

## 7. 录像

每局结束自动存到 `replays/*.json`：

```bat
vera20k.exe --replay "replays\xxx.json" --ra2-dir "<YR 数据目录>"
```

- 回放需要与录像时相同的模组状态；看旧录像先关模组或加 `--no-mod`。
- `Esc` 退出回放。

## 8. 常见问题

- **一进图就结束**：确认自己坐 **Start 1**，并且 **快速游戏 = 关**。
  Flat 30/120 的 Start 1 在可玩区菱形内、4×4 建造厂地基放得下，MCV 会正常生成并能直接展开。
- **没有全图视野**：正常 1 秒后自动亮。没亮就按 Enter 输入 `/spysat` 兜底
  （需要 `VERA.INI` 的 `SkirmishCheats=yes`）。
- **基地车没被铁幕包住**：铁幕从第 1 秒起覆盖 0 号位**周围 3×3 格**，每 10 秒补一次、
  每次 50 秒；基地车 / 建造厂待在原地就一直是无敌的，开走就脱离覆盖。
  引擎的施放动作只认 `A`–`Z` 航点字母（0–25 号航点），30 / 120 人图的这些航点全是出生位，
  没法再拿别的航点铺更大的范围，所以防护范围就是出生点这一块。
- **能不能自动展开**：不能。VERA 没有部署触发器动作，地图预置的玩家建筑也会被跳过。
  位置已经调成“进图按一次 `D` 就能展开”，不会因为贴边失败。
- **中后期还是堵**：确认自己坐 Start 1；确认地图是带 `AIHuntAll` 的版本。
- **AI 不互殴**：队伍必须关闭（FFA），不要把所有 AI 放进同一队。
- **AI 不铺建筑**：确认难度是冷酷、Ares 已启用；资金调高更明显。
- **画面太近 / 太慢**：缩放改 100%；减少 AI 数量或换更小的图。
